# AI/テンプレUIの"におい"リスト

これは「見た瞬間にAIっぽい・スターターっぽい」と感じさせる典型パターンと、その置き換え。
レビュー時は照合チェックリストとして、生成時は「これをやっていないか」の自己点検として使う。
**すべてを機械的に禁止するのではなく、"なぜそれが安く見えるか"を理解して避けること**が目的。

## 配色まわりの"におい"

| におい | なぜ安く見えるか | 置き換え |
|---|---|---|
| デフォルトの紫/藍 (`#6366f1`, `indigo-500`, violet系) | 無数のAI生成UIと同じ主役色。無個性の代名詞 | プロダクトの性格に合った主役色を自分で選ぶ |
| 純黒 `#000` / 純白 `#fff` | 自然界に無い。目が痛く、安っぽい | `#0a0a0a`〜`#1a1a1a` の off-black、`#fafafa`〜`#f7f7f5` の off-white |
| 純グレーのニュートラル (`#808080` 系) | 冷たく無機質。主役色から浮く | 主役色を数%混ぜた"色付きグレー" |
| 紫→ピンクの定番グラデ、グラデ文字 | 2021年頃のAIデモ感。中身の薄さを飾りで隠す印象 | 単色 or ごく近い2色の繊細なグラデに留める |
| 全面グラスモーフィズム / 過剰なネオン | トレンドの後追い。可読性も落ちる | 効かせどころを1箇所に絞る |
| 彩度が全部同じ | メリハリが無く画面が平坦 | 主役色は鮮やか、周辺は彩度を落とす |

## タイポの"におい"

- **見出しと本文が同じくらいの大きさ** → 情報の重みが伝わらない。タイプスケールで明確に差を。
- **なんでも中央揃え** → 読みづらく、素人っぽい。本文・リストは基本左揃え。
- **行間デフォルトのまま長文** → 本文 line-height 1.5〜1.7 を意図的に。
- **1行が長すぎる本文** → 1行 45〜75文字（日本語は全角25〜40字程度）に measure を制限。
- **絵文字を見出しに散らす（✨🚀💡）** → 一気にチープ化。使うなら機能的に1〜2箇所。

## レイアウト・コンポーネントの"におい"

- **全部同じ角丸・全部同じ影** → shadcn/Bootstrap デフォルトの典型。角丸は1〜2種に統一しつつ、
  影は「浮いている意味」があるときだけ。区切りは影より境界線や背景差で足りることが多い。
- **アイコン付き3カード横並びのヒーロー** → ランディングテンプレの最頻出構図。構成を崩す or
  情報の主従で崩す。
- **中央に1枚カードがぽつん** → 余白の使い方が単調。左右非対称や実コンテンツで密度を作る。
- **均一な `p-4` / `gap-4` の全面適用** → 余白に強弱が無い＝階層が無い。意味ごとに変える。
- **hover/focus が無い静止UI** → 触れる感触が無く"画像"に見える。状態を必ず用意。
- **空状態・ローディング・エラーが無い** → 実運用を考えていないUI。最低限のスケルトンと
  空状態メッセージを。

## "らしさ"欠如の"におい"

- そのUIを別のプロダクト（競合や無関係なSaaS）に**そのまま貼っても成立する** → 無個性。
- 記憶に残る要素が1つも無い（色、余白のリズム、1つの装飾、マイクロコピーの語り口、
  アイコンの癖 … 何か1つでいい）。
- マイクロコピーがどれも汎用（「送信」「エラーが発生しました」）→ プロダクトの声で書く。

## 使い方の注意

このリストは"減点法の刑罰表"ではなく理解の手がかり。トレンド（グラデ、グラス等）自体が
悪いのではなく、**理由なく・過剰に・効かせどころを絞らずに使うと安く見える**。1つ2つを
意図的に効かせるのは正解になり得る。
