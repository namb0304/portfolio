# 配色とタイポの実践ルール

技術非依存の考え方 + HTML/CSS と React/Tailwind の具体例。数値は出発点であり絶対値では
ないが、「なんとなく」を避けるための足場として使う。

## 配色

### 1. 主役色を1つ決める
プロダクトのキャラクター（落ち着き/機敏/高級/やわらか等）に合う色相を先に決める。
「青ならInstitutional・信頼」「緑なら安心・自然」「オレンジなら元気・食欲」のように、
色相は意味を運ぶ。Hirolia のような飲食モバイルオーダーなら、食欲を刺激する暖色や、
清潔感のある寒色などプロダクトの狙いで選ぶ。

### 2. ニュートラルを"色付き"にする
純グレーではなく主役色をわずかに混ぜると、画面全体に統一感が出る。

```css
/* 主役色 = 温かいオレンジ (hue ~25) の例 */
:root {
  --bg:        #faf8f5;  /* 白に主役色をひとさじ */
  --surface:   #ffffff;
  --border:    #eae4dc;  /* グレーではなく暖色寄り */
  --text:      #1f1a16;  /* 純黒でなく暖色寄りの off-black */
  --text-mute: #6f6459;
  --brand:     #e0592a;  /* 主役色 */
  --brand-ink: #b8421c;  /* 主役色の濃い版（hover/文字用） */
}
```

HSL で作ると関係性が管理しやすい: ニュートラルにも主役と同じ hue を与え、彩度を
2〜6% に落とす。

### 3. 使う色数を絞る
主役1・ニュートラル数段階・意味色（成功/警告/危険）だけで足りることがほとんど。
色を足すより、1色を濃淡で使い分ける方がまとまる。

### 4. コントラストを確認
本文と背景は WCAG AA（4.5:1）以上を目安に。薄いグレー文字（`#999` を白背景等）は
おしゃれに見えて読めない、の典型。

## タイポグラフィ

### 1. フォント選び
- システムフォントやInterは無難だが"無難＝無個性"にもなりやすい。プロダクトの性格に合う
  1書体を選ぶだけで印象が変わる（見出しに個性的な書体＋本文は可読性重視、の2書体構成が定番）。
- 日本語は可読性重視で（Noto Sans JP / Hiragino / BIZ UDP等）。欧文と和文でフォントを
  分けるのは有効。

### 2. タイプスケールを1本決める
サイズを場当たりに決めない。比率（1.25 = Major Third など）で刻む:

```
12 · 14 · 16(本文) · 20 · 25 · 31 · 39 px   (比率1.25)
```

見出しと本文で**最低でも1.5倍以上**の差をつけると階層が立つ。

### 3. ウェイト・行間・字間
- 見出し: 太め（600〜700）、行間つめ（1.1〜1.3）、字間わずかに詰める（-0.01em〜-0.02em）。
- 本文: 400、行間 1.5〜1.7、字間はいじらない。
- **全部を同じウェイト・同じ行間にしない。** これがのっぺり感の主因。

### 4. 揃え・measure
- 本文・リストは左揃えが基本。中央揃えは短い見出し/ヒーローのみ。
- 1行の長さ（measure）を制限: 欧文 45〜75字、和文 全角25〜40字目安。`max-width: 60ch` など。

## Tailwind を使う場合の脱デフォルト

- `indigo`/`violet` をそのまま主役にしない。`tailwind.config` の `theme.extend.colors` に
  自前ブランド色を定義して使う。
- グレーは `slate`/`zinc` など"色味のある"スケールを選ぶ、または自前の色付きニュートラルを定義。
- `rounded-lg shadow-sm border` の脊髄反射コンボを見直す。区切りは1つの手段で足りることが多い。
- 影は `shadow-xs`〜`shadow-sm` を控えめに。デフォルトの `shadow-md/lg` 多用は浮きすぎ・安っぽさの元。

## クイックチェック
- [ ] 主役色を意図して選んだ（デフォルト紫/藍のままでない）
- [ ] ニュートラルが色付き、純黒・純白を使っていない
- [ ] 見出しと本文にサイズ・ウェイト・行間の明確な差がある
- [ ] 本文の1行が長すぎない（measure制限あり）
- [ ] 本文コントラストが十分（薄すぎる文字がない）
