# レイアウト・余白・階層・コンポーネント質感

## スペーシングは"スケール1本"で管理する

4px または 8px を基準に、飛び飛びの値だけを使う:

```
4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 px
```

`13px` `17px` のような中途半端な余白が混ざると、無意識に"雑"な印象を与える。
CSS変数やTailwindのspacingスケールで縛るとブレない。

## 余白は"均一"ではなく"意味に応じて強弱"

テンプレ感の正体の多くは「全部同じ余白」。近接の原則で強弱をつける:

- **関連する要素は近づける**（ラベルと入力欄、見出しと直後の本文）。
- **無関係な要素は離す**（セクション間）。
- セクション間の余白 > グループ内の余白 > 要素内の余白、という**入れ子の大小関係**を守る。
- 「詰まって見える」原因はたいてい要素間ではなく**セクション間の余白不足**。まず外側を広げる。

例: カード内で `padding:16px` なのにカード間 `gap:16px` だと、内と外が同格で境界が
曖昧になる。カード間は `24〜32px` に開けると群としてまとまる。

## 視覚的階層 — 一目で主役がわかるか

画面を薄目で見て、最初に目が行く要素が「一番大事な要素」になっているか。
階層を作る道具:

1. **サイズ**（大きいほど主役）
2. **ウェイト/色の濃さ**（濃いほど前に出る）
3. **余白**（周りが空いているほど注目される）
4. **色**（主役色は1画面で主役級のアクションだけに）

よくある失敗: ボタンが全部同じ強さ（プライマリ/セカンダリ/テキストの区別が無い）→
一番押してほしいアクションだけ主役色の塗り、他は境界線 or テキストボタンに落とす。

## 非対称と密度でテンプレ感を崩す

- 何でも中央1カラムにせず、主従のある2カラムや、意図的な余白の偏りを使う。
- 実データで密度を作る。スカスカのダミーはテンプレに見える。

## コンポーネントの質感

### 区切りの手段は1つで足りることが多い
要素を分けるのに「境界線 + 影 + 背景差」を全部盛りしない。多くは**1つ**で十分:
- 境界線だけ（フラットで端正）
- 背景差だけ（やわらかい）
- 影だけ（浮遊・重なりに意味があるとき）

### 影は"意味"があるときだけ
影 = 「その要素が浮いている/手前にある」という物理メッセージ。モーダル・ドロップダウン・
ドラッグ中など浮く理由があるものに。並列のカード全部に影を落とすと画面が騒がしく安っぽい。

### 角丸は統一
角丸半径は1〜2種類に絞り、要素サイズに対して一貫させる。ボタン12px・カード8px・
入力4px のようにバラけると素人っぽい。1つの基準（例: 8px、内側要素は6px）で揃える。

### 状態を必ず用意する
インタラクティブ要素には最低限これを:

```css
.btn { transition: background .15s ease, transform .05s ease; }
.btn:hover  { background: var(--brand-ink); }
.btn:active { transform: translateY(1px); }
.btn:focus-visible { outline: 2px solid var(--brand); outline-offset: 2px; }
.btn:disabled { opacity: .5; cursor: not-allowed; }
```

- `:focus-visible` を消さない（キーボード操作＝アクセシビリティ）。デフォルトの outline が
  ダサいなら消すのではなく**置き換える**。
- トランジションは短く（100〜200ms）。長いと"もっさり"。

### 空・ローディング・エラー状態
実運用UIには必須。空状態は「まだ何も無い」＋次の行動を促す一文。ローディングは
スピナーよりレイアウトを保つスケルトンの方が上質に見える。

## モバイル/PWA（Hirolia的文脈）の追加観点
- タップ領域は最低 44×44px。密なリストでも押し間違えない余白を。
- 親指の届く下部にプライマリアクションを置く（親指ゾーン）。
- セーフエリア（ノッチ/ホームバー）を `env(safe-area-inset-*)` で考慮。
- ネットワークが不安定な前提で、押した瞬間のフィードバック（disabled化・ローディング）を必ず。

## クイックチェック
- [ ] 余白がスケールに沿っている（中途半端な値がない）
- [ ] セクション間 > グループ内 > 要素内、の余白階層がある
- [ ] 薄目で見て主役が一目でわかる
- [ ] 区切りを全部盛り（線+影+背景）していない
- [ ] 角丸が統一されている
- [ ] hover/focus/active/disabled と空・ローディング状態がある
